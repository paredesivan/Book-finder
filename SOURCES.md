# Fuentes y estrategia

## Integradas sin credenciales

- Google Books
- Open Library
- Internet Archive
- Project Gutenberg (catálogo servido por Gutendex)
- Wikisource
- LibriVox
- DOAB
- OAPEN Library
- Library of Congress

## Candidatas opcionales con credenciales o restricciones

Estas fuentes pueden añadirse como adaptadores sin cambiar el núcleo:

- Europeana (API key)
- DPLA (API key)
- WorldCat/OCLC (acceso institucional/API credentials)
- catálogos nacionales/regionales con SRU/Z39.50/OAI-PMH
- servicios comerciales con APIs autorizadas

## Capa web

La búsqueda web se usa para cubrir legalmente lo que las APIs no indexan: editoriales, tiendas, bibliotecas locales, repositorios universitarios, préstamo y usados. El programa genera las consultas; la capa conversacional decide qué búsquedas ejecutar y contrasta resultados.
